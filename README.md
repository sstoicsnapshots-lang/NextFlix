# NextFlix
Nextflix is a native macOS app that puts movies, TV series, and live TV/sports behind one Netflix-style interface. 
Browse and search a full TMDB-backed catalog, follow live matches with  league filters, resume
anything where you left off, and download titles to watch offline in a full native player. Apple Silicon, macOS  13+.
